## 이 저장소의 방향

Seedance 편집 프롬프트는 기존 영상을 참고해 새 장면을 만드는 생성 프롬프트와 다릅니다. 이 저장소는 원본 영상의 인물·액팅·카메라·공간·오디오를 보존하면서, 지정한 대상이나 시간 구간에만 필요한 변화를 적용하는 **정밀 편집 사고법**을 정리합니다.

핵심 구조는 간단합니다. **편집 대상과 변화량을 먼저 정의하고, 보존 목록과 물리적 일치 조건으로 나머지 장면을 잠그는 것**입니다.

## 빠른 시작

1. 작업에 맞는 버전별 가이드를 GPT 또는 Codex에 먼저 제공합니다.
2. 실제 자산 토큰과 편집할 시간 구간을 그대로 적습니다. 예를 들어 `@영상1`, `@이미지1`처럼 화면에 표시된 이름을 임의로 바꾸지 않습니다.
3. 기존 상태 A와 목표 상태 B를 작성합니다.
4. 인물·액팅·카메라·배경·오디오 중 보존해야 할 항목을 구체적으로 잠급니다.
5. 프롬프트를 한국어 검수본으로 확인한 뒤, 필요하면 동일 조건의 영문 최적화본을 사용합니다.

## 편집 계약

| 항목 | 답해야 할 질문 | 예시 |
|---|---|---|
| **대상** | 무엇을 수정하는가? | 화면 오른쪽 뒤의 흰색 건물 |
| **위치** | 어디에 있고 언제 나타나는가? | 00:02–00:05, 인물의 어깨 너머 |
| **변화** | 무엇이 무엇으로 바뀌는가? | 기존 건물 → 콘크리트 고층 건물 |
| **범위** | 전체인가, 국소 영역인가? | 건물 하나에만 적용 |
| **보존** | 무엇을 절대 변경하지 않는가? | 인물, 액팅, 카메라, 도로 |
| **물리적 일치** | 새 요소가 어떻게 장면에 붙는가? | 원근, 그림자, 가림, 모션 블러 |

## 기본 템플릿

```text
@영상1을 엄격하게 편집한다.

편집 대상은 [대상 + 위치 + 시간]뿐이다.
[기존 상태 A]를 [목표 상태 B]로 수정한다.

대상의 위치, 크기, 원근, 움직임과 깊이 관계는 원본을 유지한다.
원본 인물의 정체성, 얼굴, 신체 비율, 의상과 액팅을 그대로 유지한다.
원본 카메라 움직임, 프레이밍, 화각과 렌즈 관점을 변경하지 않는다.
지정하지 않은 영역은 다시 생성하거나 재해석하지 않는다.
```

## 작업별 진입점

| 작업 | 먼저 잠글 것 | 핵심 지시 |
|---|---|---|
| **교체** | 원본 자산과 대상 위치 | A → B, 같은 스케일·원근·움직임 |
| **삭제** | 주변 구조와 가림 관계 | 대상 제거 후 질감·그림자·반사 복원 |
| **추가** | 기존 장면의 깊이와 빛 | 접촉 그림자·원근·움직임 통합 |
| **VFX** | 인물과 카메라 | 효과의 발생 위치·원인·물리 반응 |
| **시점 변경** | 공간 구조와 행동 타이밍 | 목표 각도·높이·거리·렌즈와 복원 영역 |
| **BGM 분리** | 대사·환경음·폴리 | 제거할 스템과 보존할 스템을 구분 |

## 프롬프트를 안정시키는 규칙

> **전체 영상을 다시 만들지 말고, 바뀌는 부분을 먼저 말합니다.**

`참고하여 새로운 영상을 생성한다`보다 `@영상1을 엄격하게 편집한다`가 편집 의도를 분명하게 전달합니다. 대상은 의미·위치·시간 중 두 가지 이상으로 특정하고, 보존 목록은 인물·카메라·공간·오디오처럼 실제로 손상되기 쉬운 항목을 구체적으로 적습니다.

여러 편집이 서로 다른 영역을 다룬다면 한 프롬프트에 묶을 수 있지만, 시점 변경과 정밀 복원처럼 보존 규칙이 충돌하거나 첫 결과를 다음 편집의 원본으로 써야 한다면 단계별로 나누는 편이 안전합니다.

## 버전별 활용

Seedance 2.5 문서는 Smart Edit, Advanced Edit / Video Edit, Spatial View Modification, Audio Track Edit처럼 작업 모드를 나누어 탐색할 수 있도록 구성되어 있습니다. Seedance 2.0 문서는 원본 잠금과 Edit Delta를 중심으로 국소 교체·삭제·FX·Relighting을 설계하는 데 초점을 둡니다. 두 문서는 같은 편집 철학을 공유하지만, 실제 화면에 표시되는 자산 토큰과 UI 모드명은 사용자의 Seedance 화면을 기준으로 유지해야 합니다.
